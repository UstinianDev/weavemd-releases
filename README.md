# WeaveMD Releases

本仓库为 **WeaveMD** 的发布 / 分发仓库，仅存放编译产物与更新元数据（electron-updater 更新服务）。

- 仅包含各版本的安装包与 `latest.yml`，**不包含任何源码**。
- WeaveMD 源码位于私有项目仓库，不在本仓库公开。

## 版本安装包

| 版本 | Windows (NSIS) | Windows (MSI) |
|------|----------------|---------------|
| v1.1.0 | `WeaveMD Setup 1.1.0.exe` | `WeaveMD 1.1.0.msi` |

macOS：暂不支持（需要 macOS 系统打包）。
